## Cómo registrar el aporte

1. Cada integrante trabaja desde su propia cuenta de GitHub y realiza al menos un cambio sustancial relacionado con su frente.
2. Usen un commit descriptivo, por ejemplo: docs(avance2): documentar referencias entre motores o test(avance2): agregar capturas reales de MongoDB.
3. Integren el cambio a la rama main del repositorio existente mediante el flujo que use el equipo. Si usan ramas, abran un pull request y esperen la revisión antes de integrarlo.
4. Actualicen el estado de la tabla solo después de que el commit esté visible en GitHub.

El contenido teórico ACID/BASE/CAP y el PDF pertenecen a una etapa aparte del repositorio. El grupo es de cuatro, así que no se marca como requisito la extensión exclusiva para grupos de cinco.
